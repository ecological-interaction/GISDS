# GISDS project instructions

Read README.md and Cartography_Database_Sources.md before changing the catalogue.

- GISDS is an independent catalogue repository within Ecological Information.
- Preserve existing source IDs, research content, academic attribution and provenance.
- Distinguish platforms from datasets, analytical data from rendered imagery, and observations from classifications, models and inference.
- Verify provider documentation before changing current capabilities, access requirements or reuse conditions; record review dates and uncertainties.
- Keep dataset-specific resolution, dates, CRS, processing and licence metadata explicit.
- Keep version information inside documents and use stable filenames.
- Do not duplicate other projects' authoritative inventories or implement database integrations without a scoped request.
- Do not select a licence or publish further changes without user authorisation.
