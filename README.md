# GISDS

GISDS is an independent catalogue of GIS, cartography and Earth-observation data sources within the Ecological Information domain of Ecological Interaction.

**Status:** Initial Markdown catalogue; database implementation and integrations remain future work.

## Catalogue

Read [Cartography Database Sources](Cartography_Database_Sources.md). The current register contains 22 resources, including satellite data providers, environmental platforms, geospatial computation services and map-making tools.

It distinguishes viewing, analysis and analytical downloads, records access and interpretation limitations, and proposes dataset-level metadata fields. Existing source IDs (`RS001`–`RS022`) are stable.

## Use

No software installation is required. Read the Markdown catalogue locally or on GitHub. Follow each provider's access, attribution and reuse requirements. Platform capabilities and access conditions can change; record the checked date when reviewing an entry.

Record each dataset used separately, including its exact product/version, period, resolution, coordinate reference system, processing, licence and source. Distinguish observations, classifications, model outputs and visualisations.

## Related projects

GISDS complements EII's ecological indicator inventory, EIRKB's research and reference architecture, and AMRKB's agricultural knowledge. It remains independently maintained; shared identifiers, provenance and metadata conventions can support later interoperability without a shared runtime dependency.

## Maintenance

Keep catalogue IDs stable, retain provenance and distinguish documented capabilities from untested assumptions. Keep version notes inside documents and revisions in Git. The existing catalogue filename is retained.

Licensing and repository citation metadata have not yet been selected. Dataset reuse conditions remain those of their respective providers.
